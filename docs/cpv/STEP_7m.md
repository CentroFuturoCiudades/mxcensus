  8 and more, not specified = 98 and 99.
- **Limitation causes** (06_02A): each cause = the limited with any limitation of that cause
  (a person may have several: the shares sum to 103.7% nationally).
- **Health services** (09_04A): users = `SERSALUD` 01–08, the institutions as % of the users;
  non-users (09) and not specified (99) of all.

  religious, both); the spouse's residence on `IDENT_PAREJA_CAT` (6q's rule) — exact.
- **International migrants**: emigrants = `MPAIRES` 1–2, return migrants 3 (in the same
  dwelling `MCONRESACT` 1, elsewhere 3, not specified 9), not specified 9; Σ `FACTOR` =
  1,112,273 = INEGI's.
